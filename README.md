# 🚀 Issue Tracker API

RESTful API сервис для управления задачами и баг-трекинга, построенный на современной асинхронной архитектуре. Проект реализует полноценную ролевую модель (RBAC), безопасность на базе JWT-токенов и строгую валидацию данных.

## 🛠 Технологический стек

* **Бэкенд:** Python 3.11+, FastAPI
* **База данных:** PostgreSQL
* **ORM & Миграции:** SQLAlchemy 2.0 (async), Alembic, asyncpg
* **Аутентификация:** JWT (JSON Web Tokens), bcrypt (хэширование паролей)
* **Валидация:** Pydantic V2
* **Менеджер зависимостей:** Poetry

## ✨ Ключевые возможности

* **Аутентификация и авторизация:** Безопасная регистрация и вход с выдачей JWT-токена (OAuth2).
* **Управление доступом (RBAC):** Разделение прав на уровне эндпоинтов (Developer / Admin). Например, удаление задач доступно только администраторам.
* **Управление задачами:** CRUD операции для задач с привязкой к создателю (`author_id`) и исполнителю (`assignee_id`).
* **Фильтрация:** Динамическая фильтрация списка задач по статусу и исполнителю через Query-параметры.
* **Слоистая архитектура:** Четкое разделение ответственности между роутерами, бизнес-логикой (Pydantic-схемами) и слоем работы с данными (ORM).

## 🚀 Локальный запуск (Local Setup)

### Требования
* Установленный Python 3.11+
* Установленный [Poetry](https://python-poetry.org/)
* Локальный или удаленный сервер PostgreSQL (версия 14+)

git clone [https://github.com/ТВОЙ_НИК/tracker_api.git](https://github.com/ТВОЙ_НИК/tracker_api.git)
cd tracker_api
poetry install
